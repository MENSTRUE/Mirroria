MIRRORA UI V2 PATCH

Cara pakai:
1. Tutup Android Studio.
2. Backup project D:\porto\MIRRORA.
3. Extract isi ZIP ini langsung ke D:\porto\MIRRORA.
4. Pilih Replace files jika Windows meminta konfirmasi.
5. Buka Android Studio kembali.
6. Sync Gradle.
7. Build > Make Project.

Perubahan:
- Home lebih clean dan icon Settings menuju Profil.
- CTA utama dibuat white card tipis.
- History row lebih rapi dan konsisten.
- Score hasil dibuat card seperti preview.
- Placeholder wajah diganti silhouette formal.
- Riwayat menampilkan jumlah hasil dan pencarian lebih fleksibel.
- .gitignore diperbaiki agar build artifacts tidak ikut commit lagi.
